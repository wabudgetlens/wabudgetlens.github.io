# WA Budget Lens

Independent analysis of Washington state spending, taxes, and government performance.

## GitHub Pages setup

This repository is designed to publish directly from the root of the `main` branch.

1. Upload the contents of this folder to the repository root.
2. Commit to `main`.
3. In GitHub: **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.

The site should appear at:

`https://wabudgetlens.github.io/`

## Structure

- `index.html` - homepage
- `about.html` - project positioning and independence statement
- `methodology.html` - analytical rules and source discipline
- `reports/2026-fiscal-performance-review/` - first report landing page and public PDF
- `assets/style.css` - shared stylesheet

No analytics, cookies, external fonts, JavaScript frameworks, or third-party embeds are included in v1.
